# Circl3DS 🌸

**Circl3DS** ist ein unabhängiges Rhythmusspiel für die **Nintendo 3DS**-Konsolenfamilie (Nintendo 3DS, 2DS, New 3DS und New 2DS). Es wurde von Grund auf in C++20 unter Verwendung von `libctru`, `Citro2D` und `Citro3D` entwickelt und unterstützt Community-Beatmaps im `.osz`- und `.osu`-Format.

Das Spiel ist hochgradig optimiert, um selbst auf dem ursprünglichen Konsolenmodell (Old 3DS) mit **stabilen 60 FPS** zu laufen. Es nutzt dabei das Dual-Screen-Konzept, den Touch-Stylus sowie den **echten stereoskopischen 3D-Effekt** voll aus.

---

### 📲 Schnelle Installation (.CIA)

Lade die Datei `circl3ds.cia` herunter und installiere sie mit **FBI** auf deiner Konsole.

*Erfordert Custom Firmware (Luma3DS).*
